# Brand studies (2026-09-24)

Open the HTML files in a browser. They load three.js r128 from cdnjs, with jsdelivr as a fallback.

- **`2026-09-24-logo-studies-round1.html`:** five three.js marks: Spiral, Half-life rings, Fading h, Recall crystal, Low-poly hippo. Each has lockups and favicon previews. The Spiral was chosen and is on the site: `website/scripts/make-logo.mjs` draws the flat mark, and `website/src/components/MemorySpiral.astro` renders the live one.
- **`2026-09-24-logo-studies-round2-3d.html`:** six physically lit marks you can drag to rotate: chrome spiral, glass orb, extruded h, strata, recall knot and spiral pebble. The final pick is still open.
- **`site-mockups/`:** the five homepage directions, as Design canvas artboards (`.dc.html`): Lab Notebook, Night Recall, Platform Approved, Terminal Native and Hippocampus. The site was built from Terminal Native, with Platform Approved used for `/teams` and the receipts idea taken from Lab Notebook.

**Colour code:** mint `#7ce38b` means recalled, amber `#f2b84b` means marked wrong, on ink `#0b0f0c`. **Type:** Martian Mono and Onest.
