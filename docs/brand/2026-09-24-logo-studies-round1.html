Five marks for hippo

Each mark draws the product's one idea: memories that strengthen when used, fade when not, and drop out when wrong. The 3D version is for the website hero and video. Every mark also has to hold up flat, as a 32 px lockup and a 16 px favicon, shown under each.

Recommendation: Spiral

The spiral is a hippocampus drawn with memories. Bright nodes are recalled lessons, dim ones are fading, and one amber node is a memory marked wrong. It carries the product's whole story, it reads as a curl at favicon size, and it animates naturally: a recall pulse travelling down the curve is the hero moment on the new homepage.

Half-life rings is the strong second. It is simpler, more geometric and easier to reproduce in print, but says "decay" more than "learning".

What happens next

  • Pick a mark, or combine two (for example the spiral's nodes with the rings' geometry).
  • I draw the chosen mark as a clean SVG for favicon, npm, GitHub and slides, and keep the three.js version for the homepage hero.
  • Wordmark: Martian Mono, lower case, tight tracking, matching the Terminal Native site direction.
  • Colours: mint #7CE38B for recalled, amber #F2B84B for marked wrong, on ink #0B0F0C.
